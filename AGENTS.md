# AGENTS.md — project rules for AI agents

## NEVER touch user-curated notes without explicit permission

- The **TL;DR table** in `RESEARCH_PIPELINE.md` (`## TL;DR - one line per section`) is
  **user-curated**. The user keeps valuable hand-written notes there.
- **Never** update, reword, reformat, renumber, reorder, or regenerate that table — not as a
  side effect of another edit, not to "fix" formatting, not to add a row that seems missing.
  Only the user may change it, and only when they explicitly say so.
- Applies to other user-curated content the same way: when in doubt, ask before editing.
- Ask the user for confirmation before editing or deleting any `.md` note file whose content
  looks hand-authored (research logs, reports, summaries, notes).
